# Bug report

- **ID:** BUG-007
- **Title:** POST /booking silently coerces wrong types (depositpaid "maybe" -> true, totalprice "abc" -> null, 12.5 -> 12)
- **Endpoint:** POST /booking (TC15 and extra manual cases)
- **Severity / Priority:** Medium / P2 - wrong values are stored without any error, so client bugs go unnoticed.
- **Environment:** Local run of the upstream Restful-Booker source (github.com/mwinteringham/restful-booker, commit 619d031) at `http://localhost:3001`, Node 22, 2026-11-15. NOT yet re-run on `https://restful-booker.herokuapp.com` (blocked from the sandbox the suite was built in) - re-run the suite on the public environment before sending.

## Steps to reproduce
1. Send `POST /booking` with `"depositpaid": "maybe"` (TC15).
2. Send `POST /booking` with `"totalprice": "abc"`.
3. Send `POST /booking` with `"totalprice": 12.5`.

Reproduce with curl:

```bash
BASE=http://localhost:3001   # or https://restful-booker.herokuapp.com
curl -i -X POST $BASE/booking -H "Content-Type: application/json" -H "Accept: application/json" \
  -d '{"firstname":"Adham","lastname":"Rizk","totalprice":750,"depositpaid":"maybe","bookingdates":{"checkin":"2026-11-27","checkout":"2026-11-29"}}'
```

## Expected result (quote the contract)
Contract, Booking object: `depositpaid` -> **boolean**, `totalprice` -> **integer**; POST -> **400** when a rule is broken.

## Actual result (status, body, timing)
All three return **200**. Stored values: `depositpaid` true (from "maybe"), `totalprice` null (from "abc"), `totalprice` 12 (from 12.5, decimals dropped).

```
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8

{"bookingid":39,"booking":{"firstname":"Adham","lastname":"Rizk","totalprice":750,"depositpaid":true,"bookingdates":{"checkin":"2026-11-27","checkout":"2026-11-29"}}}
```

## Evidence
Captured output above (response time 1-3 ms, well under the 2 s limit, so only the behaviour is wrong). Automated detection: Postman: `fondoq-booking.postman_collection.json` -> folder 07 (CSV) iteration TC15 and folder 05 request 'POST /booking - totalprice as a string returns 400'; REST Assured: `BookingValidationBddTest.invalidBookingIsRejected` (TC15) and `wrongTypeIsRejected` (string and decimal price).
